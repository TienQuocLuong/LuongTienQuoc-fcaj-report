#### Event Objectives

+ Introduce modern learning strategies based on **Gamification** to help learners build sustainable study habits and maintain long-term motivation.

+ Explore **Prompt Engineering** techniques, from fundamental concepts to advanced approaches, for improving the quality and accuracy of responses generated by Large Language Models (LLMs).

+ Present the **Serverless Architecture** behind the Proptimizer project on AWS while demonstrating how cloud-native services can optimize operational costs and application scalability.

+ Introduce the **BMAD methodology**, which combines Agile practices with AI Agents to streamline software development workflows and improve team productivity.

#### Speakers

+ **Huynh Hoang Long** – Admin, First Cloud AI Journey (FCAJ).

+ **Nguyen Tuan Thinh** – DevOps/Cloud Engineer, First Cloud AI Journey.

+ **Khang** – Speaker.

+ **Thao Nguyen** – GenAI Engineer, VIB.

#### Workshop Highlights

+ **Addicted to Learning Like You're Addicted to Social Media** – *Huynh Hoang Long*

This session explained how learning motivation can be improved by applying the psychology behind dopamine and gamification. Participants learned practical techniques such as Learning Streaks, the Two-Minute Rule, and reward systems that encourage consistent learning habits and reduce procrastination.

+ **Automated Prompt Engineering: Enhancing LLM Output Quality** – *Nguyen Tuan Thinh*

The presentation introduced several prompt optimization techniques, including **Chain of Thought (CoT)**, **Self-Consistency**, **Tree of Thoughts (ToT)**, **Role Prompting**, and **Retrieval-Augmented Generation (RAG)**.

The speaker also demonstrated **Proptimizer**, a serverless AI application built on AWS using Amazon S3, CloudFront, Amazon Cognito, API Gateway, AWS Lambda, Amazon Bedrock, DynamoDB, and CloudWatch. The architecture provides scalability, cost efficiency, and simplified infrastructure management.

+ **AI-Ready Freshers: Skills and Mindset in the AI Era** – *Khang*

This session emphasized that AI should be viewed as a productivity tool rather than a replacement for human thinking. Key topics included developing a Growth Mindset, asking meaningful questions, improving critical thinking, continuous learning, and understanding the qualities employers value in technology professionals.

+ **BMAD Method – Bringing Agile & AI Agents into Your IDE** – *Thao Nguyen*

The speaker introduced the BMAD methodology, which organizes software development through specialized AI Agents such as Product Owner, Project Manager, Architect, Scrum Master, Developer, and Reviewer.

The workflow covers requirement analysis, system design, task decomposition, AI-assisted coding, testing, and code review. This approach helps reduce context overload, improve collaboration, and enhance software quality.

The workshop provided valuable insights into building effective learning habits through Gamification instead of relying solely on motivation. The concepts of Learning Streaks and reward-based learning inspired me to create a more consistent study routine.

In addition, I learned several Prompt Engineering techniques that can significantly improve the quality of AI-generated responses. The BMAD methodology also gave me a new perspective on integrating AI throughout the software development lifecycle instead of using AI only for code generation.
